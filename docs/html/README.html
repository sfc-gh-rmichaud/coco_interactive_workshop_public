What's the Art of the Possible with CoCo?

Virtual hands-on lab -- December 2, 2026, 12:00-1:30 p.m. ET Part 2 of I Downloaded CoCo Desktop... Now What?

Speakers: Rick Michaud, Senior Solution Engineer, Snowflake, and Caleb Alexander, Account Engineer, Snowflake.

You have installed CoCo Desktop and learned your way around. This session is about making it part of everyday work: framing multi-step tasks, giving useful context, shaping output for a specific audience, checking results before you use them, and saving what you learned so the next task starts ahead.

It is for analysts, data engineers, developers, data scientists, AI engineers and other Snowflake practitioners.

What you need

  • CoCo Desktop, installed, signed in and working (macOS or Windows). Linux users can follow along with the CoCo CLI or VS Code; see the prerequisites.
  • An approved, non-production Snowflake account -- sandbox, dev or trial. Do not use production.
  • **The COCO_WS_USER role**, created once by your account administrator with shared/00_admin_role_setup.sql (base grants only, down to STOP HERE). It grants CREATE DATABASE, CREATE WAREHOUSE, SNOWFLAKE.CORTEX_USER, SNOWFLAKE.COPILOT_USER and USE AI FUNCTIONS. Never run the labs as ACCOUNTADMIN.
  • This repository, downloaded (Code > Download ZIP) and opened as a project in CoCo Desktop.
  • About 30-40 minutes of prework, including running the lab setups, described in the event guide.

Can't get access in time? Watch along. Everything is written down so you can do it afterwards.

What it creates and costs

The live data labs use disposable synthetic data under COCO_WS_..._<your_user> with an XSMALL warehouse configured to suspend after 60 seconds. The expanded catalog also includes research, local-only, design-only and workspace exercises: follow each guide's setup and cleanup rather than running every SQL script.

CoCo inference, warehouse compute and other resources can incur charges. Lab 42 is a substantial stretch project with elevated privileges and resources that can continue billing while idle. Lab 74's workspace files and local skills, plugins and MCP registrations require their own cleanup; shared SQL cleanup is not universal. Do not paste credentials or sensitive production data into prompts.
